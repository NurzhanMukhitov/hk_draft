## Запреты

Нарушение любого из них — не стилистический спор, а возврат работы.

- **Не выдумывать цифры и факты.** Ни количество брендов, ни сроки, ни
  отзывы, ни сертификаты, ни год основания. Цифра появляется на сайте
  только от клиента. Вся история этого правила — в PRODUCT.md.
- **Не добавлять формы.** Заявка идёт через почту и WeChat. Форм на сайте
  нет по решению, а не по недоделке. Бэкенда тоже нет — это статика.
- **Не возвращать телефон и WhatsApp.** Убраны намеренно.
- **Не придумывать имя, логотип, слоган.** Компания — Cheng Trading
  Limited, логотипа нет, в шапке и подвале стоит плашка «LOGO HERE».
  Почта `sales@example.hk` — заглушка.
- **Не править вручную `site/src/styles/fonts.css`** в части `@font-face`.
  Файл генерируется скриптом.
- **Не класть файлы руками в `site/public/fonts/` и `site/public/images/`.**
  Это выход сборки. Оригиналы кладутся в `fonts-src/` и `images-src/`.

## Двуязычность

Английская `/` и 简体中文 `/zh-cn` равноправны.

- Все строки — в `site/src/i18n/dict.ts`, обе локали сразу.
- Заголовок героя впечатан в фотографию, поэтому у каждого языка свой
  комплект кадров. **Меняешь один — меняй второй**, кадр в кадр.
- Гонконгский адрес остаётся английским на обеих версиях: по нему ходит
  почта. Китайское написание не придумывать.

## Сборка ассетов

Оба скрипта ломаются молча: сайт соберётся, ошибки не будет, испортится
только результат. Прогонять из `site/`.

```bash
python3 scripts/build-fonts.py    # после правки текстов, особенно китайских
python3 scripts/build-images.py   # после добавления или замены картинок
```

Шрифты обрезаны до символов, которые есть в исходниках: новый иероглиф без
пересборки отрисуется системным шрифтом. Нужны `fonttools` и `brotli`.

## Разработка

```bash
cd site
npm install
npm run dev      # http://localhost:4321
npm run build && npm run preview
```

Пуш в `main` публикует сайт. Проверять сборку до пуша.

## Дизайн

DESIGN.md — источник правды. Что нарушается чаще всего:

- контент с острыми углами, интерфейс со скруглёнными;
- одна красная кнопка на экран, не две;
- золото — волосяная линия и надпись, заливка разрешена только под
  заголовком секции;
- тень только у того, что «плавает» над страницей.
